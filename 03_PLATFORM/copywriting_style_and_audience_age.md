# Copywriting Style & Audience Age — Cross-Platform Reference

Living reference. One place to see **how the copy should sound** and **who (which age / seniority band) it is talking to** on each channel, so a prompt or a caption is written for the right reader in the right voice from the start.

Last updated: 2026-09-04 (Instagram + Xiaohongshu rows refreshed with 2026-09-04 research).

**Evidence status — read first.** Every row below is built from external / industry benchmarks
(`03_PLATFORM/*.md`, `02_AUDIENCE/*.md`, `02_AUDIENCE/audience_matrix.md`,
`01_BUSINESS/company_profile.md` §30). **None is validated against Mysoft's own audience,
post performance, or sales data** — there is no first-party performance data yet
(`analyze_posting_time_performance` returns nothing for every platform). Treat all of this as
**TESTING** — a starting hypothesis for the September cycle to confirm or overturn, not a
settled style guide. Age bands are demographic skews of the *platform's Malaysian user base*
crossed with the *buying-committee role* each channel is aimed at (`company_profile.md`
§9–19), not measured Mysoft follower data.

Claim safety is not optional on any platform: every line of copy still passes
`01_BUSINESS/products.md` §30–31 (no guaranteed ROI / % improvement / zero-error / "works
with any ERP" / implementation-duration claims) and `00_SYSTEM/brain_rules.md` §7 (no
identical cross-posting — shared footage is fine, shared hook / length / structure / CTA is
not).

## The core split, in one paragraph

**Facebook is the oldest and most senior audience** (35+ owners and GMs who hold the budget) —
so the copy there is plain, concrete, problem-first, often Mandarin, and points to a WhatsApp
chat. **LinkedIn is the research audience** (GMs / Ops / Production Managers, skewing under 45
for active research) — so the copy is technical, evidence-led, written for read-through, with
no demo ask and no engagement bait, and the carousel is the format to beat. **Instagram is the
youngest and most junior** (engineers, digitalisation champions, second-gen owners who
*influence* but don't *sign*) — so the copy is minimal, the visual carries the message, and the
ask is a save or a DM, never a purchase step. The same 30–60s factory-floor video can feed
Facebook and Instagram, but the hook, caption and CTA must be rebuilt for each
(`brain_rules.md` §7).

## What this reference does NOT tell you (open gaps)

- **No Mysoft first-party data anywhere.** Age bands are platform-demographic × buying-role
  inference, not Mysoft follower analytics. Confirm against real audience data when the
  September cycle produces any.
- **No validated posting time on any channel** — `analyze_posting_time_performance` is empty;
  the September LinkedIn cycle is the first counterbalanced experiment designed to produce one.
- **WhatsApp, Google Business Profile, Xiaohongshu** are effectively unresearched — the rows
  above are placeholders.
- **SME-vs-enterprise message segmentation** (`audience_matrix.md`, 2026-09-01) is a
  2-data-point observation, not a validated segment — it should shape which message is tested
  against which prospect, not be treated as settled.
- The "younger audience influences but doesn't sign" split for Instagram is inferred from
  `company_profile.md` §18–19 buying-committee literature, **not** confirmed Mysoft deal data.
