# Customer Insights

Things learned **directly from customers and prospects**: demo feedback, sales-call
notes, WhatsApp conversations, event conversations, recurring questions, objections in
the customer's own wording. This file is first-party evidence only — it is **not** a
place for web research, competitor analysis or AI inference (those go to the other
`07_RESEARCH/` files).

If an insight hardens into a recurring deal-blocker, also summarise it in
`01_BUSINESS/customer_objections.md` (via `propose_brain_update` — that file is protected).

## Entry Template

- Date heard:
- Source (demo / sales call / WhatsApp / event / support):
- Customer / prospect (name or industry + size if name withheld):
- Role of person:
- What they said (verbatim where possible):
- Context:
- Interpretation:
- Recommended follow-up / routing:
- Confidence:
